# 智慧树刷题助手（Edge 扩展 · MV3）

在智慧树课程页 / 考试页自动识别题目，右上角浮窗给出大模型参考答案，
并在页面上高亮命中的选项。**仅提示答案，不自动作答**，把风控风险降到最低。

## 功能

- 自动检测页面题目（单选 / 多选 / 判断 / 填空 / 简答），支持视频弹题、章节测验、在线考试页
- 右上角可拖动浮窗列出所有题目与参考答案
- 答案对应的选项直接在页面上**绿色高亮**
- 同一次会话内相同题目只调用一次接口（去重省 token）
- popup 可随时开关，适配任何 OpenAI 兼容接口

## 安装（开发者模式加载）

1. 打开 Edge，地址栏输入 `edge://extensions`
2. 左下角打开「**开发人员模式**」
3. 点「**加载解压缩的扩展**」，选择本项目所在的文件夹
4. 工具栏出现 📌 图标即成功

## 配置 API Key（首次必做）

1. 打开 [open.bigmodel.cn](https://open.bigmodel.cn) 注册账号
2. 控制台 → 「API Key」→ 创建并复制
3. 点击浏览器工具栏的助手图标 → 粘贴 Key → 「测试连接」显示成功 → 保存

默认模型 `glm-4-flash` 是智谱的**免费**模型，刷课零成本。
想换 DeepSeek / Kimi 等，改接口地址和模型名即可，只要兼容 OpenAI 格式：

| 平台 | Base URL | 模型示例 |
|---|---|---|
| 智谱（默认） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 月之暗面 | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |

## 使用

打开智慧树的视频学习 / 章节测验 / 考试页面，浮窗自动出现并列出识别到的题目，
答案请求完成后会在题目上高亮正确选项。浮窗可拖动、可最小化，「⟳ 重扫」用于翻页后重新扫描。

## 识别不到题目？

不同页面 / 版本的 DOM 结构可能变化。调试方法：

1. 在题目页按 `F12`，右键题目块 → 复制 → 复制 outerHTML
2. 找到题目容器的 class 名（如 `.subject-item`）
3. 把它加进 `content.js` 顶部的 `KNOWN_SELECTORS` 列表，保存后在 `edge://extensions` 点扩展的「刷新」按钮

## 风险与注意事项

- 智慧树有切屏检测、防挂机机制，**考试环节风控更严**，本工具只显示答案不代答，请留心核对后再自己操作
- 大模型答案仅供参考，专业题可能出错，**务必自行判断**
- 本项目仅供学习交流，使用者需自行遵守所在学校及平台的相关规定
